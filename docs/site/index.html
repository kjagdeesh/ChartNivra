Key Properties

Architecture

Built for Production

Modular, extensible, and optimized — every component designed for enterprise scale.

60 FPS Real-Time

LTTB decimation and StreamingRingBuffer enable sub-millisecond ingestion with smooth 60 FPS rendering for live sensor, financial, and telemetry data.

True 3D Perspective

Camera3D projection with Painter's algorithm depth sorting and Lambertian shading — real 3D, not faked isometric, with orbit, pan, and zoom gestures.

Cross-Platform

One codebase, four platforms. Windows, iOS, Android, and macOS (Mac Catalyst) with SkiaSharp hardware-accelerated rendering on all targets.

Customizable Themes

Built-in Clean, Dark, Vibrant, Ocean palettes with live palette switching. Full XAML bindable properties — colors, fonts, borders, shadows.

Financial Suite

Candlestick, OHLC, volume bars plus SMA, EMA, RSI, MACD, Bollinger Bands, and Stochastic — everything a trading app needs.

PNG & SVG Export

Off-screen SkiaSharp rendering for server-side PNG export at any resolution. SVG vector export via the Export module with configurable DPI.

Quick Start

Up and Running in Minutes

1

Install the NuGet Package

Terminal 
dotnet add package ChartNivra.Maui --version 1.0.0
2

Register in MauiProgram.cs

MauiProgram.cs 
builder
    .UseMauiApp<App>()
    .UseChartNivra(options =>
    {
        options.DefaultTheme = ChartTheme.CleanLight;
        options.DefaultPalette = ChartPalette.Ocean;
    });
3

Add a Chart in XAML

MainPage.xaml 
<?xml version="1.0" encoding="utf-8"?>
<ContentPage xmlns="http://schemas.microsoft.com/dotnet/2021/maui"
             xmlns:cn="clr-namespace:ChartNivra.Maui;assembly=ChartNivra.Maui">

  <cn:LineChartView
      Title="Monthly Revenue"
      Series="{Binding RevenueSeries}"
      Theme="{Binding AppTheme}"
      Palette="{Binding ColorPalette}"
      ShowGrid="True"
      ShowLegend="True"
      AnimationDuration="800"
      HeightRequest="300" />

</ContentPage>
4

Bind Data in C# / MVVM

ViewModel.cs 
using ChartNivra.Core;
using ChartNivra.Maui;

public class DashboardViewModel : ObservableObject
{
    public ObservableCollection<LineSeriesModel> RevenueSeries { get; }

    public DashboardViewModel()
    {
        var series = new LineSeriesModel
        {
            Label = "Revenue",
            Smooth = true,       // cubic bezier spline
            ShowArea = true,     // gradient area fill
            Points =
            {
                new ChartPoint { X = 0, Y = 12400 },
                new ChartPoint { X = 1, Y = 15200 },
                new ChartPoint { X = 2, Y = 11800 },
                new ChartPoint { X = 3, Y = 18600 },
                new ChartPoint { X = 4, Y = 21000 },
                new ChartPoint { X = 5, Y = 19400 },
            }
        };
        RevenueSeries = new([series]);
    }
}
