True 3D Analytical Subsystem

Built with Camera3D matrix projection, Lambertian directional lighting, and back-to-front depth sorting. Actual three-dimensional spatial coordinates, not fake 2D shadows.

⚡

High-Throughput Streaming

Thread-safe StreamingRingBuffer and LttbDecimation algorithms capable of handling continuous real-time data streaming without heap reallocations.

🎨

Modern Clean Palettes

Built-in CleanLight and Dark themes with crisp typography, subtle gridlines, and categorical palettes inspired by modern SaaS applications.

📱

Cross-Platform .NET MAUI

Direct native support for Windows, iOS, Android, and macOS MacCatalyst. Simple ChartView control with full MVVM data-binding support.

📊

Financial & Statistical

Full support for Candlestick/OHLC series with technical indicators (SMA, EMA), Box Plots, and automated Histogram frequency binning.

💾

Headless PNG Exporter

Export high-resolution raster images in memory via ChartImageExporter without requiring an active UI window or screen.

Documentation & Quick Start

Get up and running in your .NET MAUI application in less than 2 minutes.

1. Install NuGet Package

dotnet add package ChartNivra.Maui

2. Add ChartView in XAML

<ContentPage xmlns="http://schemas.microsoft.com/dotnet/2021/maui"
             xmlns:charts="clr-namespace:ChartNivra.Maui.Controls;assembly=ChartNivra.Maui">

    <charts:ChartView Title="Weekly Activity"
                      Theme="{x:Static themes:ChartTheme.CleanLight}"
                      HeightRequest="300" />
</ContentPage>

3. Feed Series Data in C#

chart.Model.Series.Add(new LineSeriesModel
{
    Title = "Steps",
    Color = ChartColor.FromHex("#00C096"),
    StrokeWidth = 3.5f,
    Points = new List<ChartPoint> { new(1, 45), new(2, 52), new(3, 49), new(4, 78) }
});
