Getting Started in 2 Steps

Integrate ChartNivra directly into your existing .NET MAUI project.

Step 1: Install NuGet Package

dotnet add package ChartNivra.Maui

Step 2: Add ChartView in XAML

<charts:ChartView Title="Weekly Activity"
                  Theme="{x:Static themes:ChartTheme.CleanLight}"
                  HeightRequest="300" />
