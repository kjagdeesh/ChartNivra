Getting Started

Add ChartNivra to your .NET MAUI project in seconds.

1. Install NuGet Package

dotnet add package ChartNivra.Maui

2. Add ChartView in XAML

<ContentPage xmlns="http://schemas.microsoft.com/dotnet/2021/maui"
             xmlns:charts="clr-namespace:ChartNivra.Maui.Controls;assembly=ChartNivra.Maui"
             xmlns:themes="clr-namespace:ChartNivra.Core.Themes;assembly=ChartNivra.Core">

    <charts:ChartView Title="Weekly Activity"
                      Theme="{x:Static themes:ChartTheme.CleanLight}"
                      HeightRequest="320" />
</ContentPage>
